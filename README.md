# 🔐 Security Startup Tycoon - Full Game

A comprehensive browser-based business simulation game where you manage a cybersecurity startup from day one to industry dominance.

## 🎮 Game Overview

Start with $50,000 and build a thriving cybersecurity company. Hire talented employees, develop innovative security products, manage finances, and navigate the competitive market.

## 🎯 Core Game Systems

### 1. **Financial Management**
- Starting capital: $50,000
- Monthly expenses based on team size
- Revenue from completed projects
- Investment decisions and budgeting
- Bankruptcy mechanic if cash goes negative

### 2. **Hiring & Team Management**
- **Security Expert** ($8,000/month): Boosts security research
- **Developer** ($6,000/month): Increases project speed
- **Business Manager** ($5,000/month): Improves negotiation power
- **Security Analyst** ($4,500/month): Enhances vulnerability detection
- Employee morale affects productivity
- Limited office capacity (upgradeable)

### 3. **Project Development**
- Create custom security products
- Real-time progress tracking
- Resource allocation system
- Revenue generation upon completion
- Multiple projects can run simultaneously

Default Projects:
- Vulnerability Scanner ($5,000/month)
- Firewall Suite ($8,000/month)
- Password Manager ($6,000/month)

### 4. **Research & Development**
- AI Detection Systems
- Cloud Security
- Cryptography
- Unlock new capabilities and products
- Competitive advantage through innovation

### 5. **Market & Contracts**
- Negotiate client contracts
- Dynamic market conditions
- Reputation affects contract availability
- Scaling from startups to enterprise clients

### 6. **Infrastructure & Upgrades**
- **Office Expansion** ($20,000): +5 employee capacity
- **Server Farm** ($30,000): +50% project speed
- **Lab Equipment** ($15,000): +30% research speed
- Equipment maintenance and replacement

### 7. **Random Events**
- Major contract opportunities
- Security breaches to manage
- Market demand fluctuations
- Employee events and requests
- Competitive threats

## 📊 Victory Conditions

**Win Condition:**
- Reputation ≥ 100
- Cash ≥ $100,000
- Day reached (scale: 1 year = ~365 days)

**Loss Condition:**
- Cash falls below $0 (Bankruptcy)

## 🎮 Gameplay Loop

1. **Plan**: Allocate resources to projects, hiring, and upgrades
2. **Execute**: Advance day to process actions
3. **Monitor**: Track progress, revenue, and reputation
4. **Adapt**: Respond to random events and market changes
5. **Scale**: Expand team and infrastructure
6. **Win**: Achieve victory conditions

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Review the Dashboard for current status
3. Start by hiring your first team member
4. Create or work on projects
5. Click "Advance Day" to progress

## 💡 Strategy Tips

- **Early Game**: Focus on completing your first projects for steady revenue
- **Mid Game**: Hire specialists to boost productivity, invest in research
- **Late Game**: Scale infrastructure and pursue high-value contracts
- **Balance**: Maintain cash reserves for unexpected events
- **Reputation**: Essential for accessing better contracts and market opportunities

## 🔧 Game Mechanics

### Progress System
- Projects: 0-100% completion
- Research: 0-100% completion
- Daily advancement of progress based on team bonuses

### Reputation System
- Starts at 50
- Increases: Project completion, positive events
- Decreases: Security breaches, negative events
- Affects market opportunities

### Cash Flow
- Income: Project revenue (daily), contract bonuses
- Expenses: Employee salaries, infrastructure maintenance
- Investments: Research, upgrades, new equipment
